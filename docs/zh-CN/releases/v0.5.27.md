# v0.5.27：支持 DSH 0.2.1-alpha.2，以及与 dshmarket 并存的记忆 Source

**简体中文** | [English](../../en/releases/v0.5.27.md)

本补丁版本发布 [#360](https://github.com/omdsh-dev/dsh-mnemon/pull/360) 与 [#361](https://github.com/omdsh-dev/dsh-mnemon/pull/361)。

- **与 dshmarket 并存的记忆 Source**（[#360](https://github.com/omdsh-dev/dsh-mnemon/pull/360)，issue [#359](https://github.com/omdsh-dev/dsh-mnemon/issues/359)）。dshmarket 1.66 会为 Profile 中每个带客户端、又不是 bundle 的依赖再挂载一份，并在那里加载它的宿主代码，而这次挂载本应只提供客户端。在装有 dshmarket 的 Profile 中单独安装的记忆 Source 因此会运行两次：
  - 记忆空间每次启动都提示 `mkt-client-dsh-mnemon-source-memory-spaces` 未能激活（`Memory Spaces requires at least one explicit Provider child`）；
  - 运行时记忆与项目档案各注册第二个实例。状态页把它们的卡片显示两次，默认的分层策略让每一轮对话都以 `found ambiguous working-context Sources` 失败。

  现在在任何 DSH 版本上，这种挂载下都不会安装任何内容。运行时记忆与项目档案只需本次的 Starter；由 Profile 独立维护的记忆空间副本还需要记忆空间 0.5.18，见[升级与兼容性](#升级与兼容性)。
- **DSH 0.2.1-alpha.2**（[#361](https://github.com/omdsh-dev/dsh-mnemon/pull/361)）。v0.5.26 已适配记忆子 Agent；本版本跟进 0.2.1-alpha.2 的其余变化：
  - 它的插件页不再列出 Starter 的分组行，因此组件列表上方关于 `dsh-mnemon/bundle` 的说明只在 DSH 列出该行时显示；
  - Agent 的目录与会话的原始目录都不存在时，它会停止该 Agent，因此工作区文件夹被删除或移动后，该工作区的后台记忆任务仍操作这个工作区的记忆，并改从第一个仍存在的工作区或 DSH 的启动目录运行。

  在已安装的 0.2.1-alpha.2 与 0.2.0-rc.2 上，全部根测试、真实宿主子 Agent 测试、Headless 与 Starter 的激活契约都通过，并在 0.2.1-alpha.2 上检查了 WebUI 各流程。
- **启用 Provider 之后的记忆空间页**（[#361](https://github.com/omdsh-dev/dsh-mnemon/pull/361)）。在插件页保存或切换 Provider 时，记忆系统会同时重新加载当前打开的页面，因此该 Provider 会直接出现在记忆空间页及其创建对话框中，无需点击刷新。

## 升级与兼容性

从 v0.5.22 可使用**记忆系统 → 状态 → 检查版本 → 更新**，完成后重启 DSH。命令行安装或更新到精确版本：

```sh
dsh plugin --profile web add dsh-mnemon@0.5.27
```

安装后重启正在运行的 DSH；新安装可在插件页选择**立即启用**。明确指定版本可避免 pnpm 发布后 24 小时的等待窗口选中较早的版本。较早的桌面安装升级方式见[兼容性与升级](../reference/compatibility.md)。

如果你的 Profile 自己维护记忆空间（检查版本中显示为“Profile 独立维护”），也请把它更新到 0.5.18。宿主的 PATH 上有 pnpm 时可在检查版本中更新，否则运行：

```sh
dsh plugin --profile web add dsh-mnemon-source-memory-spaces@0.5.18
```

也可以移除这个副本，Starter 自带记忆空间。

支持的宿主为 **DSH 0.2.0-rc.2**（npm `latest` 与 `next`）；**DSH 0.2.1-alpha.2**（npm `alpha`）通过了同样的检查。在 0.2.1-alpha.2 上，在对话之下启动的记忆任务会以“可继续”留在对话的子 Agent 列表中；从那里续接它会脱离 Mnemon 的任务规则运行，请不要续接这些条目（见[兼容性说明](../reference/compatibility.md#dsh-02)）。完整 Profile 使用 Node `^22.19.0 || >=24.0.0`。

无需迁移已有记忆。本版本不需要新的 Starter SDK 导出，插件的 peer 下限保持不变。
