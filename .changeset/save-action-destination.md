Save to memory lets you choose where a reply goes. **Save to** keeps **Let the Agent decide**, where a task Agent picks a Memory Space, as the default while one can write, and adds **Working memory (MEMORY.md)**, **User profile (USER.md)** and each Memory Space by name: **Save** writes the text there as it is, at once, without a task Agent. Without a task Agent, or without a Memory Space Provider, the dialog starts on working memory instead of leaving sending closed. A receipt answers one text in one place, so the same text can go to another place without an edit, and a send that failed can be repeated as it is.

存入记忆现在可以选择回复写到哪里。**保存到**在任务 Agent 能写入时仍默认**由 Agent 决定**（由任务 Agent 选择记忆空间），另外可以选择**工作记忆（MEMORY.md）**、**用户画像（USER.md）**以及每个记忆空间：点击**保存**，原文立即写入该位置，不经过任务 Agent。没有任务 Agent，或没有记忆空间 Provider 时，对话框默认选中工作记忆，而不再无法提交。一份回执只对应一段文本和一个位置，所以同一段文本无需修改即可写入另一个位置，提交失败后也可以原样重试。
