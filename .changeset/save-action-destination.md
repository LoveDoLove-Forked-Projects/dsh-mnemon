Save to memory lets you choose where a reply goes. **Save to** keeps **Let the Agent decide**, where a task Agent picks a Memory Space, as the default while one can write, and adds **Working memory (MEMORY.md)**, **User profile (USER.md)** and each active Memory Space by name: **Save** writes the text there at once, through the same write as that place's page; no task Agent decides where it goes, though a full user profile still needs one to make room. Only places whose layer is on, whose component runs and whose writes are not switched off are listed. Without a task Agent, or without a Memory Space Provider, the dialog starts on working memory instead of failing or leaving sending closed, and it says first when the text is too long for one entry or for its file, or what making room in a full file will do. A receipt answers one text in one place, so the same text can go to another place without an edit, a send that failed can be repeated as it is, and a direct save keeps its text and receipt when the dialog is closed meanwhile.

存入记忆现在可以选择回复写到哪里。**保存到**在任务 Agent 能写入时仍默认**由 Agent 决定**（由任务 Agent 选择记忆空间），另外可以选择**工作记忆（MEMORY.md）**、**用户画像（USER.md）**以及每个已激活的记忆空间：点击**保存**，文本立即通过该位置页面所用的同一写入方式保存，不由任务 Agent 决定写到哪里；已满的用户画像整理时仍需要任务 Agent。只列出层已开启、组件在运行且没有关闭写入的位置。没有任务 Agent，或没有记忆空间 Provider 时，对话框默认选中工作记忆，而不再提交失败或无法提交；文本超过单条或整个文件上限，或文件已满需要整理时，会事先说明整理的结果。一份回执只对应一段文本和一个位置，所以同一段文本无需修改即可写入另一个位置，提交失败后也可以原样重试，直接保存进行中关闭对话框，文本与回执也会保留。
